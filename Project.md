## 📌 Project Overview

Understanding student performance and attendance patterns is critical for educational institutions to make data-driven decisions. This project cleans, transforms, and analyzes raw academic data using **Microsoft Excel** to build interactive summaries, Pivot Tables, and a visual dashboard.

* **Dataset Size:** 100,000 Rows x 16 Columns
* **Scope:** Classes 9 to 12 across 10 major Indian cities
* **Tool Used:** Microsoft Excel (Pivot Tables, Slicers, Dashboarding, Advanced Formulas)
